# Eu Fitness

App de treino e dieta para personais, nutricionistas e alunos. O agente monta o plano a partir da anamnese e os profissionais aprovam antes de o aluno receber.

## Protótipo das telas

O protótipo navegável fica em `docs/index.html` e é publicado pelo GitHub Pages:
https://euthiagosilveira-hue.github.io/eufitness/

O app de verdade (Nuxt + Tailwind + Supabase) ainda vai ser criado neste repositório.
